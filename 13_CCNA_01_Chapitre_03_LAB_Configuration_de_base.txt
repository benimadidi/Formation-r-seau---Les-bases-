----------------------------------------------
🌐 QU'EST-CE QU'UNE ADRESSE IP ? (RAPPEL SIMPLE)
----------------------------------------------

🔹 Définition simple :
   → Une adresse IP s'écrit sur 4 cases séparées par des points
   → Format : [0-255].[0-255].[0-255].[0-255]

🔹 Règle fondamentale :
   → Chaque case contient un nombre entre 0 et 255
   → Exemple valide : 192.168.1.1
   → Exemple invalide : 192.168.1.256 ← 256 est trop grand !

🔹 Structure d'une adresse IP (2 parties) :

   ┌─────────────────────────────────────────────────────────┐
   │   192 . 168 . 1   │   1                                 │
   │   ← PARTIE RÉSEAU →   ← PARTIE HÔTE →                   │
   │   (identifie le LAN)  (identifie la machine)            │
   └─────────────────────────────────────────────────────────┘

🔹 Règle d'or :
   → Deux machines dans le MÊME réseau local ont la MÊME partie réseau
   → Elles ne diffèrent que par la partie hôte

🔹 Exemple concret :
   → Machine 1 : 192.168.1.1
   → Machine 2 : 192.168.1.2
   → Machine 3 : 192.168.1.3
   → Toutes sont dans le même réseau (192.168.1.0)

🔹 Convention importante :
   → L'adresse 192.168.1.254 est souvent réservée au ROUTEUR
   → L'adresse 192.168.1.255 = adresse de broadcast (on n'y touche pas)
   → L'adresse 192.168.1.0 = adresse du réseau (on ne l'utilise pas pour une machine)

----------------------------------------------
🔄 SWITCH vs ROUTEUR : RAPPEL SIMPLE
----------------------------------------------

🔹 Switch (commutateur) :
   → Sert à BRANCHER des machines ENTRE ELLES
   → Fonctionne au niveau COUCHE 2 (adresses MAC)
   → On ne lui donne PAS d'adresse IP (pas nécessaire pour son fonctionnement)
   → Il fait simplement "tourner" le trafic dans le LAN

🔹 Routeur :
   → Sert à BRANCHER des RÉSEAUX DIFFÉRENTS
   → Fonctionne au niveau COUCHE 3 (adresses IP)
   → Chaque interface du routeur constitue un RÉSEAU différent
   → On lui DONNE une adresse IP sur chaque interface


🔹 Pourquoi le switch n'a PAS besoin d'adresse IP ?
   → Dans un réseau local, les données circulent grâce aux adresses MAC
   → Le switch lit les adresses MAC et aiguille les trames
   → Une adresse IP n'est pas nécessaire pour cette tâche

----------------------------------------------
🏗️ CONFIGURATION IP D'UN ROUTEUR (Cisco)
----------------------------------------------

🔹 Principe :
   → Chaque interface du routeur est un réseau différent
   → On configure une adresse IP sur chaque interface

🔹 Commandes (sur routeur) :
    Router> enable
    Router# configure terminal
    Router(config)# interface g0/0
    Router(config-if)# ip address 192.168.1.254 255.255.255.0
    Router(config-if)# no shutdown
    Router(config-if)# exit
    Router(config)# interface g0/1
    Router(config-if)# ip address 192.168.2.254 255.255.255.0
    Router(config-if)# no shutdown
    Router(config-if)# end
    Router# copy running-config startup-config

🔹 Explication :
   → interface g0/0 : on choisit l'interface (GigabitEthernet 0/0)
   → ip address : on donne l'adresse IP et le masque
   → no shutdown : on allume l'interface (active physiquement)
   → copy running-config startup-config : on sauvegarde

----------------------------------------------
📌 À RETENIR 
----------------------------------------------

1️⃣ Adresse IP = 4 cases [0-255] séparées par des points

2️⃣ Une adresse IP a 2 parties : RÉSEAU + HÔTE
   → Deux machines dans le même LAN = même partie réseau

3️⃣ Switch = Couche 2 (MAC) → Pas besoin d'adresse IP pour faire tourner le trafic

4️⃣ Routeur = Couche 3 (IP) → Besoin d'une adresse IP sur CHAQUE interface

5️⃣ Chaque interface d'un routeur = un RÉSEAU DIFFÉRENT

6️⃣ no shutdown = allumer l'interface (toujours faire après ip address)
