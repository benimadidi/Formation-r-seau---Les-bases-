----------------------------------------------
🏷️ 1. LE MASQUE PAR DÉFAUT
----------------------------------------------

🔹 Rappel :

   → Le découpage en classes (A, B, C) n'est plus vraiment
     utilisé aujourd'hui
   → MAIS il reste la méthode PAR DÉFAUT de tous les
     constructeurs d'équipements réseau
   → Pourquoi ? Monsieur tout-le-monde ne sait pas calculer
     un masque → l'équipement le calcule à sa place

🔹 Démonstration sous Windows (configuration IP) :

   | Adresse saisie | Classe | Masque proposé automatiquement |
   |----------------|--------|--------------------------------|
   | 10.0.0.1       | A      | 255.0.0.0                      |
   | 172.16.1.1     | B      | 255.255.0.0                    |
   | 192.168.1.1    | C      | 255.255.255.0                  |

🔹 Ce que Windows refuse :

   → 192.168.1.0   → ERREUR : c'est l'adresse du RÉSEAU
     (première adresse, réservée pour identifier le réseau)
   → 192.168.1.255 → ERREUR : c'est l'adresse de DIFFUSION
     (dernière adresse, réservée au broadcast)

🔹 Comment le masque est construit :

   → Toute la partie RÉSEAU (Network) = bits à 1
   → Toute la partie HÔTE (Host)      = bits à 0

   Exemple classe B : 172.16.1.1

      11111111.11111111.00000000.00000000
      └──255──┘└──255──┘└───0───┘└───0───┘
        RÉSEAU   RÉSEAU    HÔTE     HÔTE

   → 8 bits à 1 = 255 (pas besoin de calculer, c'est toujours 255)
   → 8 bits à 0 = 0

----------------------------------------------
⚖️ 2. RÈGLE D'OR DU MASQUE
----------------------------------------------

🔹 Un masque s'écrit TOUJOURS :

   → Une série de 1 (partie réseau) À GAUCHE
   → suivie d'une série de 0 (partie hôte) À DROITE
   → On ne mélange JAMAIS : pas de 1 après un 0

   ✅  11111111.11111111.11100000.00000000
   ❌  11111111.00000000.11111111.00000000

🔹 Conséquence pratique :

   → Dès qu'un octet n'est plus 255 (le 255 est « cassé »),
     il y a un 0 quelque part
   → Donc TOUS les octets suivants valent 0
   → Pas besoin de réfléchir !

🔹 Exemples :

   | Masque               | Valide ? | Pourquoi                         |
   |----------------------|----------|----------------------------------|
   | 255.128.64.0         | ❌ NON   | Après 128, il faut 0 (pas 64)    |
   | 255.128.0.0          | ✅ OUI   | 1 suivi de 0 jusqu'à la fin      |
   | 255.224.1.0          | ❌ NON   | Après 224, il faut 0 (pas 1)     |
   | 255.255.250.0        | ❌ NON   | 250 n'est pas une valeur de masque|

   ⚠️ 255.255.250.0 a l'air bon (255 cassé puis 0)...
      mais 250 = 11111010 → un 0 au milieu des 1 → INVALIDE

----------------------------------------------
🔢 3. LES 9 VALEURS POSSIBLES D'UN OCTET DE MASQUE
----------------------------------------------

🔹 Un octet de masque ne peut valoir QUE :

   | Nb de bits à 1 | Binaire  | Décimal |
   |----------------|----------|---------|
   | 0              | 00000000 | 0       |
   | 1              | 10000000 | 128     |
   | 2              | 11000000 | 192     |
   | 3              | 11100000 | 224     |
   | 4              | 11110000 | 240     |
   | 5              | 11111000 | 248     |
   | 6              | 11111100 | 252     |
   | 7              | 11111110 | 254     |
   | 8              | 11111111 | 255     |

🔹 Pourquoi ?

   → Les 1 s'ajoutent toujours par la GAUCHE
   → Le premier 1 vaut 128, puis on cumule :
     128 → +64 = 192 → +32 = 224 → +16 = 240
     → +8 = 248 → +4 = 252 → +2 = 254 → +1 = 255

   💡 Le but n'est pas d'apprendre par cœur mais de
      COMPRENDRE (à force de pratique, on les retient)

----------------------------------------------
🎭 4. À QUOI SERT LE MASQUE ? LA NOTATION CIDR
----------------------------------------------

🔹 Le problème :

   → Si je vous donne 172.16.1.1 sans rien d'autre,
     IMPOSSIBLE de savoir où s'arrête la partie réseau
   → La notation par classes est abandonnée (depuis ~1995)

🔹 La solution : LE MASQUE

   → Il « masque » la partie réseau
   → Une adresse IP est donc TOUJOURS donnée avec son masque
   → Sans masque, on ne peut pas séparer réseau et hôte

🔹 La notation CIDR :

   → On écrit : ADRESSE / nombre de bits de la partie réseau

   Exemple : 172.16.1.1/20

      → 20 premiers bits = partie RÉSEAU
      → 12 bits restants (32 − 20) = partie HÔTE

   → Le /20 EST le masque, écrit de façon courte
   → C'est grâce à ce chiffre qu'on écrit le masque décimal

----------------------------------------------
🔄 5. CONVERTIR UN /n EN MASQUE DÉCIMAL
----------------------------------------------

🔹 Méthode rapide :

   ① Comparer n aux paliers 8, 16, 24
   ② Chaque bloc complet de 8 bits = 255
   ③ Les bits qui restent → table des 9 valeurs
   ④ Tout le reste = 0

🔹 Exemple : /20

   → 20 > 16 → deux octets à 255
   → Il reste 20 − 16 = 4 bits → 240
   → Le reste = 0

   11111111.11111111.11110000.00000000
   = 255.255.240.0

🔹 Repères à connaître :

   | /n   | Masque          |
   |------|-----------------|
   | /8   | 255.0.0.0       |
   | /16  | 255.255.0.0     |
   | /24  | 255.255.255.0   |
   | /32  | 255.255.255.255 |

----------------------------------------------
📊 6. LE TABLEAU MAGIQUE
----------------------------------------------

🔹 À dessiner sur votre brouillon à CHAQUE exercice :

   Puissance  : 2⁷   2⁶   2⁵   2⁴   2³   2²   2¹   2⁰
   Valeur     : 128  64   32   16   8    4    2    1
   Nb bits    : 1    2    3    4    5    6    7    8
   Masque     : 128  192  224  240  248  252  254  255

   → Ligne « Nb bits » : on numérote de GAUCHE à DROITE
     (le masque se remplit toujours de gauche à droite)
   → Ligne « Masque » : chaque case = case précédente
     + valeur du dessus (128, 128+64, 192+32...)

🔹 Pourquoi un octet s'arrête à 255 (et pas 256) :

   → 128+64+32+16+8+4+2+1 = 255
   → 2⁸ = 256 appartient déjà à l'octet suivant

🔹 Bonus – conversion binaire → décimal :

   Exemple : 10110010
   → 128 + 32 + 16 + 2 = 178

   ⚠️ Si la conversion binaire/décimal n'est pas claire,
      revoir la vidéo sur le système numérique (leçon 16)

----------------------------------------------
🧮 8. CALCULER RÉSEAU, PLAGE UTILISABLE ET DIFFUSION
----------------------------------------------

🔹 Les 4 informations à trouver pour chaque adresse :

   → Adresse RÉSEAU         : bits hôte tous à 0
   → Première adresse       : adresse réseau + 1
   → Dernière adresse       : diffusion − 1
   → Adresse de DIFFUSION   : bits hôte tous à 1

🔹 Exemple complet : 192.168.16.38/19

   ① Le masque :
      → 19 = 16 + 3 → 255.255.224.0

   ② Repérer l'octet « intéressant » :
      → Octets 1 et 2 : masque 255 → on garde tel quel
      → Octet 4 : masque 0 → partie hôte → 0
      → Octet 3 : masque 224 → c'est LÀ qu'il faut calculer

   ③ Écrire l'octet 3 (16) en binaire :

      16 = 000 | 10000
           └─┘   └───┘
         bits 17-19  bits hôte
         (RÉSEAU,    (mis à 0)
         « sacrés »,
         on n'y touche
         jamais)

   ④ Mettre la partie hôte à 0 :
      → 000 00000 = 0

   ⑤ Résultat :

   | Information          | Valeur              |
   |----------------------|---------------------|
   | Masque               | 255.255.224.0       |
   | Adresse réseau       | 192.168.0.0/19      |
   | Première adresse     | 192.168.0.1         |
   | Dernière adresse     | 192.168.31.254      |
   | Diffusion            | 192.168.31.255      |

🔹 Calcul de la diffusion :

   → Partie réseau : inchangée (000 dans l'octet 3)
   → Partie hôte : tous les bits à 1
   → Octet 3 = 000 11111 = 16+8+4+2+1 = 31
   → Octet 4 = 11111111 = 255
   → Diffusion = 192.168.31.255

🔹 ⚡ Astuce pour aller vite :

   → Valeur suivante dans le tableau − 1
   → 00011111 : les 1 s'arrêtent à 16 → la valeur suivante
     est 32 → 32 − 1 = 31
   → 01111111 : les 1 s'arrêtent à 64 → valeur suivante
     128 → 128 − 1 = 127

   (Ajouter 1 à 00011111 donne 00100000 = 32,
    c'est comme 9 + 1 = 10 en décimal)

🔹 Corrigé complémentaire – 10.0.1.5 avec chaque masque :

   | /n  | Réseau      | 1re adresse | Dernière adresse | Diffusion      |

----------------------------------------------
📌 À RETENIR
----------------------------------------------

1️⃣ Le masque sépare la partie RÉSEAU (bits à 1)
   de la partie HÔTE (bits à 0)
   → Sans masque, une adresse IP est incomplète

2️⃣ Règle d'or : des 1 à gauche, puis des 0 à droite
   → Dès que le 255 est cassé, tout le reste vaut 0

3️⃣ Un octet de masque ne vaut que :
   0, 128, 192, 224, 240, 248, 252, 254, 255

4️⃣ Notation CIDR : adresse/n
   → n = nombre de bits de la partie réseau
   → /20 = 255.255.240.0

5️⃣ Le tableau magique :
   → 128 64 32 16 8 4 2 1
   → 128 192 224 240 248 252 254 255

6️⃣ Pour toute adresse :
   → Réseau     = bits hôte à 0
   → Diffusion  = bits hôte à 1
   → 1re adresse = réseau + 1
   → Dernière    = diffusion − 1

7️⃣ Astuce diffusion : valeur suivante du tableau − 1
   (ex. 00011111 → 32 − 1 = 31)
