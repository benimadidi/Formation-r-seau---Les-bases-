----------------------------------------------
🌍 1. LA COUCHE RÉSEAU (COUCHE 3)
----------------------------------------------

🔹 À partir de la couche 3, on parle de tout ce qui est LOGIQUE :
   → Adressage entre les réseaux
   → Routage des paquets

🔹 La couche réseau effectue 4 opérations de base :

   ① ADRESSAGE
      → Des périphériques finaux (IP source/destination)
      → Des réseaux (adressage logique)

   ② ENCAPSULATION
      → Les données de la couche transport (segments) sont encapsulées dans des paquets IP

   ③ ROUTAGE
      → Trouver le meilleur chemin pour acheminer les paquets

   ④ DÉCAPSULATION
      → Retirer l'en-tête IP à la destination pour récupérer le segment

🔹 Les 3 caractéristiques fondamentales du protocole IP :

   ═══════════════════════════════════════════════════════════
   ① SANS CONNEXION (Connectionless)
      → Le protocole IP ne vérifie PAS si la destination est disponible
      → Pas d'établissement de session préalable
      → Analogie : la poste dépose le courrier, elle ne vérifie pas si le destinataire est là
   ═══════════════════════════════════════════════════════════

   ② ACHEMINEMENT AU MIEUX (Best Effort)
      → IP fait son MAXIMUM pour livrer le paquet
      → Mais ne garantit PAS la livraison
      → Pas d'accusé de réception, pas de vérification
      → Principe : engagement de MOYEN, pas engagement de RÉSULTAT
   ═══════════════════════════════════════════════════════════

   ③ INDÉPENDANT VIS-À-VIS DES SUPPORTS (Media Independent)
      → IP ne dépend PAS du support physique (cuivre, fibre, Wi-Fi, satellite...)
      → Le paquet IP sera converti en trame adaptée au support
      → C'est le rôle de la couche 2 (liaison de données)
   ═══════════════════════════════════════════════════════════

🔹 Protocoles IP distincts :
   → IPv4 (32 bits) → adresses de type 192.168.1.1
   → IPv6 (128 bits) → adresses de type 2001:db8::1


----------------------------------------------
📦 2. PAQUET IPv4
----------------------------------------------

🔹 L'en-tête IPv4 contient des informations essentielles :
   → Garantit que le paquet est envoyé vers la meilleure direction
   → Contient des informations pour la gestion de couche réseau
   → Utilisé par tous les périphériques de couche 3

🔹 Structure simplifiée de l'en-tête IPv4 (20-60 octets) :

   ┌─────────────────────────────────────────────────────────────────────────────┐
   │                         EN-TÊTE IPv4                                        │
   ├──────────┬──────────┬───────────────────────┬───────────────────────────────┤
   │ Version  │ IHL      │ Type of Service (ToS) │ Total Length                  │
   ├──────────┴──────────┴───────────────┬───────┴────────┬──────────────────────┤
   │ Identification                      │ Flags          │ Fragment Offset      │
   ├─────────────────────────────────────┴────────────────┴──────────────────────┤
   │ Time to Live (TTL) │ Protocol       │ Header Checksum                       │
   ├─────────────────────────────────────┴───────────────────────────────────────┤
   │ Source IP Address (adresse source)                                          │
   ├─────────────────────────────────────────────────────────────────────────────┤
   │ Destination IP Address (adresse destination)                                │
   └─────────────────────────────────────────────────────────────────────────────┘

🔹 Champs les plus importants pour :

   | Champ             | Taille | Rôle                                         |
   |-------------------|--------|----------------------------------------------|
   | Version           | 4 bits | Indique IPv4 (4) ou IPv6 (6)                 |
   | Total Length      | 16 bits| Taille totale du paquet                      |
   | TTL (Time To Live)| 8 bits | Évite les boucles (diminue à chaque routeur) |
   | Protocol          | 8 bits | Protocole encapsulé (TCP=6, UDP=17, ICMP=1)  |
   | Source IP         | 32 bits| Adresse IP de l'émetteur                     |
   | Destination IP    | 32 bits| Adresse IP du destinataire                   |

🔹 Le Time To Live (TTL) :
   → 1, 2, 3... au départ (ex: 64, 128, 255 selon l'OS)
   → Chaque routeur diminue le TTL de 1
   → Arrivé à 0 → le routeur rejette le paquet (évite les boucles infinies)
   → Analogie : une lettre avec une date d'expiration


----------------------------------------------
⚠️ 3. LIMITES DE IPv4 ET SOLUTION IPv6
----------------------------------------------

🔹 Les limites de IPv4 :

   ① Le nombre d'adresses IPv4 est limité à 4,2 MILLIARDS
      → 2^32 = 4 294 967 296 adresses

   ② Explosion d'Internet dans les années 90 (boom dotcom)
      → Pénurie d'adresses IPv4

   ③ Solutions temporaires :
      → NAT (Network Address Translation)
      → PAT (Port Address Translation)
      → DHCP (adresses attribuées temporairement)

🔹 Le NAT (Network Address Translation) :
   → Une seule adresse publique pour plusieurs machines privées
   → Le routeur traduit les adresses privées en adresse publique
   → Inconvénient : perte de performance

🔹 Le PAT (Port Address Translation) :
   → Version "avancée" du NAT
   → Une même adresse IP publique pour 50, 100, 500 personnes
   → Utilise les NUMÉROS DE PORT pour identifier les sessions

🔹 Limitations du NAT/PAT :
   → Complication du réseau
   → Perte de bande passante (temps de traduction)
   → Problèmes pour certaines applications (voix, vidéo)

🔹 La solution : IPv6
   → Espace d'adressage BEAUCOUP PLUS GRAND
   → Traitement PLUS EFFICACE des paquets
   → PLUS de NAT nécessaire !


----------------------------------------------
🔢 4. PAQUET IPv6
----------------------------------------------

🔹 L'en-tête IPv6 est SIMPLIFIÉ par rapport à IPv4 :

   ┌─────────────────────────────────────────────────────────────────────────────┐
   │                         EN-TÊTE IPv6 (40 octets)                            │
   ├────────────────────┬───────────────────┬────────────────────────────────────┤
   │ Version (4 bits)   │ Traffic Class (8) │ Flow Label (20 bits)               │
   ├────────────────────┴───────────────────┴────┬───────────────────────────────┤
   │ Payload Length (16 bits)                    │ Next Header (8 bits)          │
   ├─────────────────────────────────────────────┴───────────────────────────────┤
   │ Hop Limit (8 bits) - équivalent du TTL                                      │
   ├─────────────────────────────────────────────────────────────────────────────┤
   │ Source IP Address (128 bits)                                                │
   ├─────────────────────────────────────────────────────────────────────────────┤
   │ Destination IP Address (128 bits)                                           │
   └─────────────────────────────────────────────────────────────────────────────┘

🔹 Différences clés IPv4 vs IPv6 :

   | Caractéristique         | IPv4                     | IPv6                          |
   |-------------------------|--------------------------|-------------------------------|
   | Taille adresse          | 32 bits (4 octets)       | 128 bits (16 octets)          |
   | Nombre d'adresses       | 4,2 milliards            | 340 undécillions (énorme)     |
   | Taille en-tête          | 20-60 octets (variable)  | 40 octets (fixe)              |
   | Diffusion (Broadcast)   | OUI                      | NON (remplacé par multicast)  |
   | NAT                     | Nécessaire               | INUTILE                       |
   | TTL / Hop Limit         | TTL (Time To Live)       | Hop Limit (même principe)     |
   | Encapsulation           | Plus complexe            | Plus efficace                 |

🔹 Les avantages de IPv6 :
   → PLUS besoin de NAT (traduction d'adresse)
   → Traitement des paquets PLUS RAPIDE
   → Plus de diffusion (broadcast) → remplacée par multicast
   → Plus de sécurité (IPsec intégré)

🔹 Champs importants de IPv6 :
   → Version = 6
   → Traffic Class = équivalent du ToS (Quality of Service)
   → Payload Length = taille des données (pas de l'en-tête)
   → Next Header = type de protocole encapsulé (équivalent de Protocol)
   → Hop Limit = équivalent du TTL

----------------------------------------------
📌 À RETENIR 
----------------------------------------------

1️⃣ Couche réseau = adressage LOGIQUE (IP) + ROUTAGE

2️⃣ IP = sans connexion + best effort + indépendant du support

3️⃣ IPv4 = 32 bits = 4 octets = 4,2 milliards d'adresses

4️⃣ IPv6 = 128 bits = 16 octets = espace énorme, pas de NAT

5️⃣ TTL (IPv4) / Hop Limit (IPv6) = évite les boucles

6️⃣ NAT/PAT = solutions temporaires pour pallier le manque d'adresses IPv4
