🏗️ 1. RAPPEL : LA CARTE RÉSEAU (NIC)
----------------------------------------------

🔹 Définition :
   → NIC = Network Interface Card (carte réseau)
   → Pièce MAÎTRESSE des réseaux
   → Permet de rendre un périphérique connectable au réseau

🔹 Rôle :
   → Assure la connexion physique (câblée ou sans fil)
   → Prépare les données pour la transmission
   → Gère le codage des bits en signaux

🔹 Avant toute communication réseau :
   → Une connexion physique au réseau local DOIT être établie
   → Cette connexion peut être filaire (câble) ou sans fil (Wi-Fi)
   → Cela s'applique à : maison, entreprise, PME, siège social


----------------------------------------------
📡 2. RÔLE DE LA COUCHE PHYSIQUE (LAYER 1)
----------------------------------------------

🔹 Définition (officielle CCNA) :
   → La couche physique transporte des BITS sur le support réseau
   → Elle accepte une trame complète de la couche liaison de données
   → Elle code cette trame sous forme d'une série de signaux
   → Ces signaux sont transmis sur le support local

🔹 Place dans le modèle OSI :
   → C'est la COUCHE 1 (la plus basse)
   → C'est la DERNIÈRE ÉTAPE du processus d'encapsulation
   → C'est par elle que les données QUITTENT l'équipement

🔹 Schéma de positionnement :

   ┌─────────────────────────────────────────────┐
   │ Couches supérieures (7 à 2)                 │
   │         ↓ (encapsulation)                   │
   │ Couche 2 - Liaison → TRAME                  │
   │         ↓                                   │
   │ COUCHE 1 - PHYSIQUE → BITS + SIGNAL         │
   │         ↓                                   │
   │ Support réseau (câble, fibre, air)          │
   └─────────────────────────────────────────────┘


----------------------------------------------
📊 3. CARACTÉRISTIQUES DE LA COUCHE PHYSIQUE
----------------------------------------------

🔹 Les 3 domaines fonctionnels des normes de couche physique :

   ═══════════════════════════════════════════════════════════
   ① COMPOSANTS PHYSIQUES
   → La carte réseau (NIC)
   → Les interfaces (ports RJ45)
   → Les connecteurs et le câblage
   ═══════════════════════════════════════════════════════════

   ② CODAGE (Encoding)
   → Définition : c'est une TRADUCTION des bits en signaux
   → Traduit les 0 et 1 en impulsions électriques/lumineuses/radio
   → Exemples de codage :
        • Codage Manchester : utilisé dans Ethernet classique
        • NRZ (Non Return to Zero) : plus simple, moins fiable
   ═══════════════════════════════════════════════════════════

   ③ SIGNALISATION
   → C'est la façon dont les valeurs sont représentées physiquement
   → Complète le codage
   → Exemples : variations de tension, modulation d'onde
   ═══════════════════════════════════════════════════════════

🔹 Organismes de normalisation de la couche physique :

   | Organisme | Rôle principal                                      |
   |-----------|-----------------------------------------------------|
   | ISO       | Normalisation internationale (modèle OSI)           |
   | EIA/TIA   | Normes de câblage (TIA/EIA 568)                     |
   | ITU-T     | Normes pour télécommunications et WAN               |
   | ANSI      | Normes américaines (Fibre, ATM)                     |
   | IEEE      | Normes Ethernet (802.3) et Wi-Fi (802.11)           |


----------------------------------------------
📈 4. BANDE PASSANTE, DÉBIT ET LATENCE
----------------------------------------------

🔹 BANDE PASSANTE (Bandwidth) - Capacité maximale :
   → Quelle est la capacité d'un support à transporter des données ?
   → Analogie : combien de personnes peuvent passer une porte en même temps ?
   → Valeur THÉORIQUE (maximum possible)
   → Unité : bits par seconde (bps)

🔹 LATENCE (Latency) - Temps de traversée :
   → Temps nécessaire pour que les données circulent du point A au point B
   → Inclut tous les retards (propagation, traitement, file d'attente)
   → Unité : millisecondes (ms)

🔹 DÉBIT (Throughput) - Mesure réelle :
   → Mesure du transfert des bits à travers les médias sur une période donnée
   → Valeur RÉELLE (ce qui passe vraiment)
   → Toujours inférieur ou égal à la bande passante théorique

🔹 Tableau comparatif :

   | Concept       | Définition simple                    | Type         | Unité     |
   |---------------|--------------------------------------|--------------|-----------|
   | Bande passante| Capacité MAXIMALE (théorique)        | Fixe         | bits/s    |
   | Débit         | Mesure RÉELLE à l'instant T          | Variable     | bits/s    |
   | Latence       | Temps de traversée (retard)          | Variable     | ms        |


----------------------------------------------
🔌 5. CÂBLAGE CUIVRE
----------------------------------------------

🔹 Pourquoi le câble cuivre est-il LE PLUS RÉPANDU ?
   → ✅ Pas cher (coût faible)
   → ✅ Facile à installer
   → ✅ Faible résistance à la circulation du courant électrique

🔹 Inconvénients majeurs :
   → ❌ Qualité limitée sur longue distance
   → ❌ Atténuation : plus le signal circule longtemps, plus il s'affaiblit
   → ❌ Sensible aux interférences électromagnétiques

🔹 L'ATTÉNUATION :
   → Définition : la perte de puissance du signal sur la distance
   → Plus on va loin, plus le signal est faible
   → Solution : répéteurs ou changeur pour longues distances


----------------------------------------------
📦 6. TYPES DE CÂBLES CUIVRE
----------------------------------------------

🔹 Câble UTP (Unshielded Twisted Pair - Paire torsadée non blindée) :
   → LE PLUS RÉPANDU dans les réseaux Ethernet
   → Débit possible : jusqu'à 1 Gbps (et plus avec Cat6/Cat7)
   → Composition : 3 parties
        • Gaine externe : protège contre les dommages physiques
        • Paires torsadées : protègent le signal des interférences
        • Isolation plastique : isole électriquement les fils entre eux

🔹 Câble STP (Shielded Twisted Pair - Paire torsadée blindée) :
   → Protection et isolation MEILLEURES que l'UTP
   → ❌ Plus cher
   → ❌ Plus difficile à installer
   → Composition : 4 parties
        • Gaine externe
        • Blindage tressé (feuille) : protège contre le bruit externe
        • Blindage en aluminium pour chaque paire
        • Paires torsadées

🔹 Câble COAXIAL :
   → Historiquement : câble de la télévision
   → 4 couches :
        • Gaine externe
        • Tresse de cuivre tissé
        • Couche d'isolation plastique flexible
        • Conducteur en cuivre (âme centrale)


----------------------------------------------
📋 7. NORMES ET CATÉGORIES DES CÂBLES UTP
----------------------------------------------

🔹 Norme principale : TIA/EIA 568
   → Créée par TIA et EIA (organismes de normalisation)
   → Normalise : types de câbles, longueurs, connecteurs, méthodes de test

🔹 Norme IEEE 802.3 :
   → Définit les CATÉGORIES de câbles
   → Chaque catégorie correspond à des performances spécifiques

🔹 Tableau des catégories :

   | Catégorie  | Débit max  | Fréquence | Utilisation typique           |
   |------------|------------|-----------|-------------------------------|
   | Cat 3      | 10 Mbps    | 16 MHz    | Ancien, téléphone             |
   | Cat 5      | 100 Mbps   | 100 MHz   | Obsolète                      |
   | Cat 5e     | 1 Gbps     | 100 MHz   | Standard actuel (le + courant)|
   | Cat 6      | 1 Gbps     | 250 MHz   | Meilleures performances       |
   | Cat 6a     | 10 Gbps    | 500 MHz   | Haut débit                    |
   | Cat 7      | 10 Gbps+   | 600 MHz   | Blindé, installations pro     |

🔹 Règle : plus la catégorie est élevée, plus la qualité est bonne

🎨 8. NORMES DE BRANCHEMENT : T568A vs T568B
----------------------------------------------

🔹 Deux standards pour terminer les câbles RJ45 :
   → T568A (norme EIA/TIA)
   → T568B (norme AT&T)

🔹 Code couleurs T568A :
   ┌─────────────┬───────────────────────────────────┐
   │ Broche      │ Couleur                           │
   ├─────────────┼───────────────────────────────────┤
   │ 1           │ Blanc/vert                        │
   │ 2           │ Vert                              │
   │ 3           │ Blanc/orange                      │
   │ 4           │ Bleu                              │
   │ 5           │ Blanc/bleu                        │
   │ 6           │ Orange                            │
   │ 7           │ Blanc/marron                      │
   │ 8           │ Marron                            │
   └─────────────┴───────────────────────────────────┘

🔹 Code couleurs T568B (LE PLUS COURANT) :
   ┌─────────────┬───────────────────────────────────┐
   │ Broche      │ Couleur                           │
   ├─────────────┼───────────────────────────────────┤
   │ 1           │ Blanc/orange                      │
   │ 2           │ Orange                            │
   │ 3           │ Blanc/vert                        │
   │ 4           │ Bleu                              │
   │ 5           │ Blanc/bleu                        │
   │ 6           │ Vert                              │
   │ 7           │ Blanc/marron                      │
   │ 8           │ Marron                            │
   └─────────────┴───────────────────────────────────┘

🔹 Observation : les paires 1 (orange) et 2 (vert) sont inversées
🔹 À savoir : la norme T568B offre une meilleure résistance au bruit selon les sources


----------------------------------------------
🔀 9. TYPES DE CÂBLES (CONFIGURATION DES BROCHES)
----------------------------------------------

🔹 Câble DROIT (Straight-through) :
   → Les deux extrémités : T568A – T568A ou T568B – T568B
   → Utilisation : hôte → périphérique (PC → switch)
   → Le type le plus courant

🔹 Câble CROISÉ (Crossover) :
   → Une extrémité T568A, l'autre T568B
   → Utilisation : hôte ↔ hôte, switch ↔ switch, routeur ↔ routeur
   → Permet à deux équipements identiques de communiquer

🔹 Câble INVERSÉ (Rollover - Cisco) :
   → Configuration propriétaire CISCO
   → Utilisation : câble console (PC → port console routeur/switch)
   → Les broches sont totalement inversées

🔹 Tableau récapitulatif :

   | Type de câble | Standard                  | Application principale              |
   |---------------|---------------------------|-------------------------------------|
   | DROIT         | Même standard (A/A ou B/B)| PC → Switch, Switch → Routeur       |
   | CROISÉ        | A à B                     | Switch ↔ Switch, PC ↔ PC            |
   | INVERSÉ       | Propriétaire Cisco        | Console (configuration)             |


----------------------------------------------
⚙️ 10. AUTO-MDIX (FONCTIONNALITÉ CISCO)
----------------------------------------------

🔹 Définition :
   → Auto-MDI/MDIX = détection AUTOMATIQUE du type de câble
   → Le périphérique s'adapte : droit ou croisé, ça fonctionne

🔹 Comment ça marche ?
   → Pendant la négociation automatique (auto-negotiation)
   → L'interface détecte la configuration de câble
   → Elle effectue la correction si nécessaire

🔹 Commande Cisco (sur une interface) :
    Switch(config-if)# mdix auto

🔹 Conditions de fonctionnement :
   → Auto-MDIX nécessite la vitesse en AUTOMATIC (auto-negotiation)
   → Par défaut, c'est ACTIVÉ sur les switches Cisco modernes

🔹 Tableau des états Auto-MDIX :

   | Config locale | Config distante | Câble correct | Câble incorrect |
   |---------------|-----------------|---------------|-----------------|
   | Auto-MDIX ON  | Auto-MDIX ON    | Link UP       | Link UP         |
   | Auto-MDIX ON  | Auto-MDIX OFF   | Link UP       | Link UP         |
   | Auto-MDIX OFF | Auto-MDIX OFF   | Link UP       | Link DOWN       |

   → Avec Auto-MDIX, le lien fonctionne MÊME avec un mauvais câble


----------------------------------------------
🔬 11. CODAGE ET SIGNALISATION (DÉTAILS)
----------------------------------------------

🔹 Pourquoi coder les bits ?
   → Permet la synchronisation entre émetteur et récepteur
   → Évite la perte de signal sur les longues suites de 0 ou de 1

🔹 Codage MANCHESTER :
   → Utilisé dans l'Ethernet classique (10 Mbps)
   → Chaque bit est représenté par une TRANSITION :
        • Bit 1 : transition haut → bas
        • Bit 0 : transition bas → haut
   → Avantage : synchronisation incluse dans le signal
   → Désavantage : nécessite 2x plus de bande passante

🔹 Codage NRZ (Non Return to Zero) :
   → Plus simple : 1 = tension positive, 0 = tension négative
   → Moins coûteux en bande passante
   → Inconvénient : perd la synchronisation sur les longues suites de 0

📌 À RETENIR 
----------------------------------------------

1️⃣ La couche physique = les BITS + le SUPPORT (câble, onde, fibre)

2️⃣ 3 domaines : Composants physiques + Codage + Signalisation

3️⃣ Bande passante = capacité MAXIMALE (théorique) → bits/s
   Débit = mesure RÉELLE (toujours inférieur)
   Latence = TEMPS de traversée (ms)

4️⃣ UTP = le plus courant (Cat5e = 1 Gbps, Cat6/7 = plus haut débit)

5️⃣ Normes de câblage : T568A et T568B 

6️⃣ 3 types de câbles Ethernet :
   → DROIT (PC→switch)
   → CROISÉ (switch→switch)
   → INVERSÉ (console Cisco)

7️⃣ Auto-MDIX = détection automatique du type de câble (actif par défaut sur Cisco)

8️⃣ Codage Manchester = transition pour chaque bit (synchro incluse)
